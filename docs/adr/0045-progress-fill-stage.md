# ADR 0045: 擬似プログレスバーの段階に fill を加える

- ステータス: 採用([0043](0043-loading-feedback-thumbnail-spinner-and-fake-progress.md) の段階の一覧を変更)
- 日付: 2026-10-01

## コンテキスト

[0044](0044-fill-regions.md) で、検出する要素の種類に塗りつぶし(fill)を加えました。ページ解析中の擬似プログレスバー([0043](0043-loading-feedback-thumbnail-spinner-and-fake-progress.md))は、検出する種類の名前を段階として順に表示しています。しかし、そこに fill が含まれておらず、表示と検出する種類が一致していませんでした。

## 決定

- 段階を `raster → text → fill → line → curve → rect → 解析結果まとめ` の7段階にします。fill は、ユーザーの指定で text の次に置きます
- fill の割合は text と同じにします
  - 時間: 最後の段階より前の6段階に、基準時間の90%を均等に配分します(配分の方法は変えていません)
  - 表示幅の重み: text と同じ 1 にします

## 理由

- プログレスバーの段階は見た目上の演出ですが、画面の凡例と同じ種類の名前を並べておくと、利用者が何を検出しているのか分かりやすくなります
- 時間の配分の方法を変えずに段階を1つ加えるだけにすると、全体の見積もり時間は変わりません

## 影響

- 見積もりの合計時間は変わりません。最初の各段階の時間は、基準時間の90%の1/5から1/6に短くなります
- 実際の処理段階と連動しない演出であることは、[0043](0043-loading-feedback-thumbnail-spinner-and-fake-progress.md) と同じです
