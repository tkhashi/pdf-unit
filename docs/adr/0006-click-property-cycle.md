# ADR 0006: クリックで属性を巡回し、選択中の属性は属性パネルの行で示す

- ステータス: 採用(「選択」欄を別に設ける当初案を置き換え)
- 日付: 2026-09-24

## コンテキスト

クリックすると同じプロパティを持つ要素がすべてハイライトされ、クリックするたびに比べる属性が切り替わる機能が求められた。当初は属性パネルの下に「選択: linewidth = 1.5 (4610件)」と巡回の手順を別欄で表示したが、UX が悪いのでホバー時の属性表示の該当行をハイライトする形にしてほしいと指摘された。

## 決定

- 属性の巡回順を種類ごとの定義(`STROKE_LEVELS` / `TEXT_LEVELS` / `IMAGE_LEVELS`)として持つ。各定義は「ラベル・値の取り出し方・任意の一致判定」の組
- 同じ要素を再クリックすると次の属性へ進む。それまでに表示した集合と同じ結果になる属性は飛ばし、最後まで行ったら選択を解除する
- 比較対象は同じ系統(線・文字・画像)の中だけ
- 属性パネルは同じ定義から行を生成する。選択中の属性の行を黄色背景にして件数を付ける。別の要素にホバーしても、その要素が集合に含まれていれば同じ行が光る

## 理由

- 表示と巡回を同じ定義から作れば、属性の追加が1か所で済み、表示と判定が食い違わない
- 同じ集合を飛ばさないと、補正係数がページ内で1つの「描画太さ」のように、見た目が変わらないクリックが挟まる
- 独立した「選択」欄より、既に見ている属性一覧の中で示す方が、何で絞り込んでいるかが直感的に分かる

## 影響

- 一致判定を差し替えられるため、「値が等しい」では表せない形状比較([0007](0007-curve-shape-similarity.md))を同じ仕組みに載せられた
