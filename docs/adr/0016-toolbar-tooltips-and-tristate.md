# ADR 0016: ツールバーは値を簡潔に示し、機能の説明はマウスオーバーの補足に任せる

- ステータス: 採用([0015](0015-ui-labels-and-controls.md) の一部を置き換え。補足の表示方法は [0017](0017-custom-tooltip-and-toolbar.md) で変更)
- 日付: 2026-09-25

## コンテキスト

[0015](0015-ui-labels-and-controls.md) の変更後、ユーザーから次の指摘を受けた。

- サムネイル一覧の開閉バーは、一覧の左ではなく右側に表示してほしい
- 「すべて非表示」という言葉は冗長。視覚的に直感で分かる、よくあるUIで表現してほしい
- 「線幅補正なし(実測に使える孤立した直線が不足)」は、そもそも何の値なのかがひと目で分からず、説明も分かりづらい。この場合は「-」でよい。これを含め、上部ツールバーはマウスオーバーで機能を簡単に補足してほしい

## 決定

- 開閉バーは一覧の右(一覧と図面の境目)に置く。並びは「サムネイル一覧 → 開閉バー → 図面」
- 一括切替は、文言付きのボタンをやめ、よくある「すべて選択」チェックボックスにする
  - 全部表示中: チェック
  - 一部だけ表示中: 不確定状態(`indeterminate`、「−」)
  - 全部非表示: 空
  - 押すと、全部表示中なら全部非表示、それ以外なら全部表示
  - 凡例の先頭に置き、区切り線で個別チェックと分ける
- 線幅補正はツールバーに値だけを出す。係数を算出できた場合は「線幅補正 ×0.18」、できなかった場合は「線幅補正 -」
- ツールバーの全項目に `title` 属性でマウスオーバーの補足を付ける
  - 対象: PDFを開く / ページ選択 / 表示切替 / 一括チェック / 種類ごとのチェック / 原本の濃さ / 線幅補正
  - 補足の文言はフロント側の定数(`TYPE_LABELS`、`CALIBRATION_NOTES` 等)として持つ
  - 種類ごとのチェックは「直線の表示/非表示(9564件)」のように日本語の種類名と件数を示す
  - 原本の濃さは現在の値(%)を示す
  - 線幅補正は、係数の意味(描画太さ = 線幅 × 係数)と算出方法・算出できなかった理由を示す

## 理由

- 開閉バーを一覧と図面の境目に置くと、一覧の端を畳む操作として位置から直感的に分かる
- 3状態の一括チェックはメールやファイル一覧などで広く使われており、文言を読まなくても現在の状態(全部 / 一部 / なし)と操作の意味が分かる
- ツールバーは常に目に入るため、値だけを簡潔に出す。意味や理由は必要なときだけマウスオーバーで読めれば十分で、常時表示の説明文は情報を探しにくくする

## 影響

- ツールバーの横幅が縮み、折り返しが起きにくくなった
- ヘルプ(`?`)の文言は従来どおり index.html の `title` 属性に直書き
