# ADR 0007: 曲線の同一形状は弧長再標本化と直交プロクラステスで判定する

- ステータス: 採用
- 日付: 2026-09-24

## コンテキスト

curve のクリック巡回に「同一形状」を加えたいという要件があった。回転・反転・拡大縮小・平行移動を含めて同じ形なら同一とみなす。ただし X 方向だけ拡大するような非一様な拡大には対応しなくてよい。

## 決定

- 前処理(読み込み時に1回): 曲線の折れ線を弧長で等間隔の64点に取り直し、重心を原点に移してノルム1に正規化した複素数列にする。始点と終点が近ければ閉曲線として扱う
- 比較: 正規化した複素ベクトル a, b の内積の絶対値 `|⟨a,b⟩|` は、回転と一様拡大を最適に当てはめたときの一致度になる(直交プロクラステス)。次の候補すべてで最大値を取る
  - 反転: `conj(b)`
  - 逆向き: b を逆順にする
  - 閉曲線の始点のずれ: 64通りの巡回シフト
- 判定: `sqrt(1 − |⟨a,b⟩|²) < 0.03`(形状サイズ比で約3%の誤差)なら同一形状。閉曲線と開曲線は区別する
- 巡回順では line の「長さ」と同じ位置(種類で排他)に置く

## 理由

- 相似変換だけを最適化するので、非一様な拡大は自然に一致しなくなり、要件の除外条件をそのまま満たす
- 弧長で取り直すので、元のパスの頂点数や分割のされ方に依存しない
- 起点と全 curve を比べるのはクリック時だけなので、ハッシュ化せず直接比べても十分速い

## 影響

- 回転37°+2.5倍+平行移動、X軸反転+0.3倍、逆向き、閉曲線の始点ずらしはすべて一致し、X方向のみ2倍は不一致になることを確認した
- 1回の巡回は参考図面(curve 1,206本)で7ms、大判図面(curve 8,422本)で39ms
- 許容誤差 `SHAPE_TOL` と点数 `SHAPE_N` は `index.html` の定数
