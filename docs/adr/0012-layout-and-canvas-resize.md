# ADR 0012: 画面は flex レイアウトにし、Canvas の画素サイズを表示領域に常に追従させる

- ステータス: 採用
- 日付: 2026-09-25

## コンテキスト

次の2点を指摘された。

- 原本と再描画を比べると、拡大すれば位置が一致するが、縮小すると下の方ほどずれている(上端は合っている)
- 上部ヘッダーのテキストが画面からはみ出ている

原因は共通していた。

- Canvas の画素サイズは起動時と画面サイズ変更時にしか合わせていなかった
- ヘッダーは高さ44px固定・折り返し無しで、ページ読み込み後に凡例が入ると横にはみ出し、表示領域の大きさが変わった
- Canvas は古い画素サイズのまま CSS で縦に押し縮められて表示され、上端を基準に下ほどずれていた

## 決定

- `body` を縦方向の flex にし、表示領域(`#viewport`)を `flex: 1` にする。ヘッダーの高さが変わっても表示領域が追従し、スクロールバーも出ないようにする(`overflow: hidden`)
- ヘッダーは折り返しを許可し、長い操作説明は `?` のツールチップへ移す
- `ResizeObserver` で表示領域を監視し、大きさが変わるたびに Canvas の画素サイズを合わせて描き直す

## 理由

- 画面サイズ変更イベントだけでは、ヘッダーの折り返しやスクロールバーの出現、サイドバーの開閉による表示領域の変化を捉えられない。表示領域そのものを監視するのが確実

## 影響

- ヘッドレス Chrome で、全体表示と縮小時のスクリーンショットを縦4帯に分けて原本と照合し、全帯でずれ0pxを確認した。ヘッダーを3行に伸ばしても追従した
- 後で追加したサムネイル一覧([0013](0013-page-thumbnails.md))の開閉も同じ仕組みで追従する
